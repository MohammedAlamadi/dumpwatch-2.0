# Dataset access

The repository README contains the current retrieval, directory-structure and configuration instructions. Task A comes from https://github.com/MiviaLab/IllegalWasteDumping via its official Drive partition links, not video blobs in this repository. Validate against frozen per-file hashes after downloading.

Task B's exact `dumpwatch_real_dataset.zip` is shared privately with the instructor via a restricted Google Drive link sent by email. That link and all photographs are intentionally absent. Put the unchanged ZIP at `Data/Real/dumpwatch_real_dataset.zip` or configure `DUMPWATCH_REAL_ZIP`. Preserve all location and pair manifests. Do not unpack, flatten or re-zip the original archive for evaluation.

Synthetic V1 data is optional for historical experiments, obtained through authorized private access. Access references are redacted from the public allowlist; content hashes are retained. Academic/private marking permission does not imply public redistribution permission.
