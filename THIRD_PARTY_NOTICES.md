# Third-party software, weights and datasets

Dependencies are installed separately; their upstream licences continue to apply. Python, NumPy, Pillow, SciPy/scikit-learn, joblib, PyTorch/torchvision, Streamlit, matplotlib, Jupyter and FFmpeg are not relicensed by this repository. Consult the relevant official distribution and FFmpeg build licence.

ResNet-18 implementation and ImageNet weight reference: https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.resnet18.html . Torchvision source licence: https://github.com/pytorch/vision/blob/main/LICENSE . The original official encoder is retrieved separately and checked against SHA-256 f37072fd47e89c5e827621c5baffa7500819f7896bbacec160b1a16c560e07ec. Third-party dataset rights are not inferred from the software licence.

Task A source and requested citations: https://github.com/MiviaLab/IllegalWasteDumping and `Data/MIVIA_CITATIONS.bib`. Raw videos and derived photographic previews are excluded. The official README provides Google Drive partition links; a complete independently downloaded snapshot has not been verified by this packaging process.

Task B real photographs and historical synthetic source assets are private inputs. Academic use/private marking permission does not authorize public image release. The instructor's private Drive link is deliberately absent. Portable metadata retains labels, reviewed crops, partition IDs and content hashes while access URLs/IDs in the synthetic allowlist are redacted. No new dataset licence or personal contribution statement is invented.
